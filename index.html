Check writer features

The Rust writer now supports rich-text runs, whole Geometry row replacement, connector insertion, pictures/media relationships, shape add/remove, text, Shape Data and cell/row patches, plus fresh package output. The browser editor exposes the same operations:

  • Rich text: double-click a shape and use the paragraph/run inspector.
  • Connector: choose Connect, then click a source and target shape.
  • Picture: choose Picture and pick an image.
  • Add/remove shape: drag from the palette or select and press Delete.
  • Patch/fresh export: use Save as Visio; imported packages are patched, new diagrams are written fresh.
