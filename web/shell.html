      AI assistant (MCP)

      An AI assistant can draw with LayoutCraft through its Model Context Protocol (MCP) server. The server is a separate program: the assistant (the MCP client) starts it and talks to it over standard input and output, nothing is sent over the network. It can read and write files only below the drawings folder you give it.

      This build includes the server; the program path is filled in.

      Claude Desktop and other clients that read a JSON configuration

      In Claude Desktop: Settings > Developer > Edit Config, add the layoutcraft entry to mcpServers, then restart it.

      Claude Code

      Run it once in a terminal; claude mcp list shows the server.

      The tools and an example are listed in docs/32-mcp.md. An assistant that is connected can change the files below the drawings folder, so give it a folder you are happy to share.
