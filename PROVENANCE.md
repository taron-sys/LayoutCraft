# Provenance statement

LayoutCraft is an independent implementation of a VSDX-compatible diagram editor. The public repository contains no Microsoft source
code, binary code, stencil artwork, icons, templates or proprietary fonts.

## What a behaviour may rest on

A behaviour implemented in this project must be justified by evidence of one of these kinds, and the evidence should be recorded next
to the code:

- public file-format documentation (for example the published VSDX, OPC and DrawingML specifications);
- files the application itself generates or saves;
- ShapeSheet cells read through the published COM automation interface;
- observable COM state;
- rendered page output.

This list says what evidence a behaviour needs. It is **not** a claim that these were the only sources ever consulted, and it is **not**
a claim of a separated-team process.

## What the project does not claim

- It does not claim a separated-team process.
- It does not claim that any behaviour was derived only from public documentation.

## Third-party material in the public repository

- `web/fonts/` contains open-licensed fonts (Liberation, Carlito, Caladea) with their licence files. Proprietary fonts are not
  redistributed; VSDX font names are preserved only as names and rendering falls back.
- Rust and npm dependencies are inventoried in `THIRD-PARTY-NOTICES.txt`; every dependency offers a permissive licence compatible with
  MIT OR Apache-2.0.
- `fixtures/public/` is generated by LayoutCraft's own engine from our own drawing operations and is recorded as self-authored and
  redistributable (`fixtures/public/provenance.json`, `docs/39-fixture-replacement.md`).
- The public repository contains no Visio-authored drawing, Visio-exported page image, vendor stencil or Microsoft binary. The
  Visio-authored validation corpus and the Visio-rendered visual oracle are private and are not distributed (`docs/38-private-fixtures.md`).
- Vendor and product names in source comments and tests are descriptive references to private validation inputs (for example a
  rack-equipment stencil), not copied assets. They identify what motivated a rule; they do not imply that the vendor's artwork is
  included.
- "Visio" and ".vsdx" are used only descriptively, to say which file format is supported. The project does not suggest an affiliation
  with Microsoft and uses no Microsoft marks or logos.

## Evidence kept privately

Maintainers keep a private provenance ledger, the Visio probe/check scripts and their captured evidence. Those records show the basis
for each behaviour and are available to the owner and to counsel; they are not part of the public repository.

## If you find a problem

Report a vulnerability privately as described in [`SECURITY.md`](SECURITY.md). For a provenance or licensing concern, contact the
maintainers privately rather than opening a public issue.
